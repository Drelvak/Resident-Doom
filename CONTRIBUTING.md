# Contributing

Pull requests are welcome. Drelvak reviews all changes to the official project, and inclusion is at the maintainer's discretion.

Do not submit copyrighted proprietary game assets, game executables, IWADs, converted game models/audio/art, animation dumps or generated playable packages. Keep changes scoped to the E1M1 prototype. Preserve upstream notices and identify any third-party code you adapt.

Contributions must be compatible with this project's GPL-3.0-only license. No contributor is granted repository write/admin access by submitting a contribution.
